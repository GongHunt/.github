# 공모전헌터 (GongHunt)

개발자 대회를 모아 보여주고, 공고마다 핏이 맞는 팀원을 추천해 팀 결성부터 결과 기록까지 잇는 서비스입니다.

- 해커톤, AI 경진대회, 서비스 개발 공모전처럼 직접 만들어야 하는 대회만 다룹니다.
- 역할, 목표, 투입 시간, 기술 스택을 기준으로 팀원을 추천하고, 요청 → 채팅 → 팀 확정까지 한곳에서 진행합니다.
- 대학생부터 시작해 현업 개발자까지 넓혀 갑니다.
